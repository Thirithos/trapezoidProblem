This folder contains all of the problem instances used in the paper:

Lewis, R., X. Song, K. Dowsland, and J. Thompson (2011) 'An Investigation into two Bin Packing Problems with Ordering and Orientation Implications'. European Journal of Operational Research, vol. 213, pp. 52-65.

The 1300 Truss Cutting Problems can be found in the "Truss" folder, together with a description of their layout and naming convention. Note that these will need to be altered in order to produce the "half" and "quarter" instances described in the above paper.

The single box-cutting instance, together with a description, can be found in the "Box" folder. This was used for all of the experiments described in Section 4, though the values for \alpha and W were altered as described in the paper.

For comparison purposes, the data used to generate the graphs in figures 8 and 11 of the above publication are included in the excel spreadsheet "plotdata.xlsx".
